# Uber NCR Ride Booking Dashboard (Microsoft Excel)

## 📌 Project Overview

This project is an interactive Microsoft Excel dashboard developed to analyze Uber ride booking data across the NCR region. The dashboard provides key operational insights using Pivot Tables, Pivot Charts, KPI Cards, and Slicers.

---

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Visualization

---

## 📊 Dashboard Features

- Interactive KPI Cards
- Ride Booking Analysis
- Booking Status Analysis
- Vehicle Category Analysis
- Payment Method Distribution
- Trip Distance Analysis
- Pickup Location Insights
- Dynamic Slicers
- Business Insights Panel

---

## 📈 Key KPIs

- Total Bookings
- Total Revenue
- Average Booking Value
- Average Trip Distance
- Average Trip Time

---

## 💡 Business Insights

- Identifies peak booking trends.
- Compares vehicle category performance.
- Analyzes payment method preferences.
- Highlights booking status distribution.
- Supports data-driven operational decisions.
