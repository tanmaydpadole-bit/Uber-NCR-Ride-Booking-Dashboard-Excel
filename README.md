# 🚖 Uber NCR Ride Booking Dashboard (Microsoft Excel)

An interactive Microsoft Excel dashboard developed to analyze Uber ride booking data across the NCR region. The dashboard provides actionable business insights through KPI cards, Pivot Tables, Pivot Charts, and dynamic Slicers.

## 📌 Project Overview

This dashboard helps analyze Uber ride booking performance by tracking key operational metrics and identifying booking trends. It enables users to explore the data interactively using filters and visualizations.

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Visualization

---

## 📊 Dashboard Features

- 📌 Interactive KPI Cards
- 📈 Booking Trend Analysis
- 🚗 Vehicle Category Analysis
- 💳 Payment Method Distribution
- 📍 Pickup Location Analysis
- 📏 Trip Distance Analysis
- 📋 Booking Status Analysis
- 🎛️ Interactive Slicers
- 💡 Business Insights Panel

---

## 📈 Key Performance Indicators (KPIs)

- Total Bookings
- Total Revenue
- Average Booking Value
- Average Trip Distance
- Average Trip Time

---

## 💡 Business Insights

- Identifies peak booking periods.
- Analyzes booking status distribution.
- Compares vehicle category performance.
- Highlights customer payment preferences.
- Supports operational and business decision-making.

## 🚀 How to Use

1. Download the Excel workbook.
2. Open it in Microsoft Excel (2019 or Microsoft 365 recommended).
3. Enable editing if prompted.
4. Use the slicers to interact with the dashboard.
